# Fibo Trend Strategy — استراتيجية الفيبو ترند

استراتيجية مأخوذة من فيديو «شرح استراتيجية الفيبو ترند» (SPX500، فريم 5 دقائق) ومحوَّلة إلى Pine Script v6 لـ TradingView، مع ربط تنبيهاتها بـ GitHub.

## قواعد الاستراتيجية (كما في الفيديو)

| المستوى | الدور |
|---|---|
| **1** | بداية الموجة الدافعة — الوقف خلفه |
| **0.65 – 0.5** | منطقة الدخول (التصحيح) |
| **0** | نهاية الموجة الدافعة |
| **-0.6** | الهدف الأول |
| **-1.1** | الهدف الثاني |
| **-1.6** | الهدف الثالث (منطقة ارتداد متكررة في الفيديو) |
| **-1.9** | الامتداد الأقصى |

1. حدد آخر موجة دافعة (قاع ← قمة للشراء، أو قمة ← قاع للبيع) وارسم الفيبو: 1 على بدايتها و0 على نهايتها.
2. انتظر رجوع السعر لمنطقة **0.5 – 0.65**.
3. ادخل عند ظهور شمعة رفض من المنطقة (خضراء للشراء، حمراء للبيع).
4. الوقف خلف مستوى **1**، والأهداف على **-0.6 / -1.1 / -1.6**.
5. يُلغى السيناريو إذا أغلق السعر خلف مستوى 1 قبل الدخول، أو انتهت صلاحيته.

> السكربت يحدد الموجات تلقائياً بالـ Pivots، ويغلق 40% عند TP1 و30% عند TP2 والباقي عند TP3، وينقل الوقف لنقطة الدخول بعد TP1 (كلها قابلة للتعديل من الإعدادات). فلتر EMA 200 مفعّل افتراضياً ويمكن إيقافه.

## التركيب على TradingView
1. افتح **Pine Editor** في أسفل الشارت.
2. الصق محتوى `pine/fibo_trend_strategy.pine` واضغط **Add to chart**.
3. افتح **Strategy Tester** لرؤية نتائج الباك تست.

## الربط مع GitHub

```
TradingView Alert ──webhook──▶ Cloudflare Worker ──API──▶ GitHub Action ──▶ signals/signals.csv
```

TradingView لا يسمح بإضافة Headers للـ webhook، لذلك نستخدم Worker صغير مجاني يضيف توكن GitHub.

1. **GitHub**: أنشئ Fine-grained token بصلاحية *Contents: Read & write* على هذا الريبو.
2. **Cloudflare Workers**: أنشئ Worker والصق `webhook/worker.js`، وأضف المتغيرات:
   `GITHUB_TOKEN` ، `GITHUB_REPO` (مثل `9a999a/fibo-trend`) ، `PASSPHRASE`.
3. **TradingView**: أنشئ تنبيه على الاستراتيجية ← الشرط: *Any alert() function call* ← فعّل **Webhook URL**:
   `https://<worker>.workers.dev/?key=<PASSPHRASE>`
4. كل إشارة تُسجَّل تلقائياً في `signals/signals.csv` مع commit جديد.

> ملاحظة: الـ webhook في TradingView يحتاج اشتراك مدفوع.
